# About

![리소스팩 활성화시](/image/enable.png)

- 마인크래프트에서 HD 폰트를 사용합니다.
- 한국어를 지원합니다.
- 기울임 글꼴을 지원합니다.
- 굵은 글꼴을 지원합니다.
- 프리텐다드 폰트를 사용했습니다.
- 프리나인다드 폰트는 기움일 글꼴을 구현하기 위해 만들어졌으며 라이선스에 따라 이름이 변경되었습니다.
- 기본 값은 굵은 글꼴이며 굵은 글씨는 블랙(더 굵은 글꼴)으로 표시됩니다.

# Require

- **이 리소스팩을 사용하기 위해선 [Caxton 모드](https://modrinth.com/mod/caxton)가 필요합니다.**
- 굵은 글씨와 발광 글자를 구현하기 위해 해당 모드가 필요합니다.

# Warning

- **만일 [BBE](https://modrinth.com/mod/better-block-entities)이나 [More Culling](https://modrinth.com/mod/moreculling) 모드를 사용하고 있다면 지워주세요**.
- 해당 모드를 사용하는 경우 발광 글씨가 제대로 표시되지 않을 수 있습니다.
- 확실한 해결 방법을 찾지는 못했습니다.
- 반드시 사용해야 한다면, 표지판 글자 컬링 옵션과 텍스쳐 필터링 옵션을 계속 바꾸면서 리소스팩 새로 고침을 몇 번 진행해 주세요.
